#  Java Learning Journey — 100 Projects

A hands-on Java learning journey built around **100 practical projects**, progressing from basic console programs to object-oriented programming, file handling, data structures, algorithms, and combined real-world applications.

The goal is to learn Java by **building**, not just reading theory.

---

##  Goal

By completing these 100 projects, I will progressively learn:

* Java syntax and program structure
* Variables and data types
* User input and console output
* Conditions and loops
* Arrays and strings
* Object-Oriented Programming (OOP)
* File I/O
* Exception handling
* Collections and data structures
* Algorithms and mathematics
* Real-world programming patterns
* Combining multiple Java concepts into complete applications

#  Recommended Project Workflow

For every project:

1. Read the goal.
2. Understand the required concepts.
3. Create the Java file.
4. Write the program yourself.
5. Compile and run it.
6. Test different inputs.
7. Fix errors and improve the code.
8. Write/update the project documentation.
9. Commit the project to Git.
10. Move to the next project.

---

#  Testing

For each program, test:

* Normal input
* Minimum values
* Maximum values
* Invalid input where applicable
* Empty input where applicable
* Unexpected cases
* Boundary conditions
