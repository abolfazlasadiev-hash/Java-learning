# Hello World

A simple Java program that prints **"Hello, World!"** to the console.

##  Goal


The goal of this project is to learn the basic structure of a Java program and how to display output in the console.

##  Concepts

### 1. Class

Every Java program is built using classes.

```java
public class Main {
}
```

The class is named `Main`.

### 2. Main Method

The `main()` method is the starting point of the Java program.

```java
public static void main(String[] args) {
}
```

When the program runs, Java starts executing the code inside the `main()` method.

### 3. System.out.println()

This is used to print text to the console.

```java
System.out.println("Hello, World!");
```

### 4. String

`"Hello, World!"` is a String, which represents text in Java.

##  Code

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

##  How to Run

Save the file as:

```text
Main.java
```

Compile the program:

```bash
javac Main.java
```

Run it:

```bash
java Main
```

##  Output

```text
Hello, World!
```
